# GlyphsHero Case Study Pass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bring GlyphsHero's case study to the same content, visual and provenance standard Rollhaus and FerMentor already have, by replacing description with real evidence: two data-driven diagrams sourced from the game repo's own docs, one real screenshot, and two independent copy corrections.

**Architecture:** Content-only, on infrastructure that already exists. No new `Section` kind and no new component pattern: the two new diagrams are `embed` sections following the `glyphshero-chain`/`rollhaus-slots` data-plus-component shape, the one new screenshot is a plain `figure` section, and both ship through the existing `scripts/extract-figures.py` pipeline, which gains its first `glyphshero` entries. `src/content/projects.ts`'s GlyphsHero record goes from five sections to eight; two independent prose fixes (`PRODUCT.md`, `_build-log.md`) round it out.

**Tech Stack:** Next 16.2.12 (`output: 'export'`), React 19.2.4, Tailwind v4 via `@theme inline` over Style Dictionary tokens, Vitest 4, PyMuPDF for figure extraction.

## Global Constraints

- **No em-dashes anywhere in `src/content/**`**, and by CLAUDE.md guardrail 5, nowhere in this pass's prose either (`PRODUCT.md`, `_build-log.md`). `tests/unit/copy.test.ts` walks every string in every content module via `import.meta.glob` and fails on `—`, `TODO`, `TBD`, `FIXME`, bracketed-caps placeholders, and lorem ipsum. It walks eagerly, so a new content file fails this the moment it exists, before anything references it.
- **No colour literals, Tailwind palette classes, or raw type/motion properties outside a role.** `tests/unit/token-discipline.test.ts` scans `src/**` and `public/**`. `src/content/**` is exempt from the hex rule only. Neither new component in this plan needs a literal colour; both render on Semantic tokens exclusively, the same way `glyphshero-chain.tsx` does.
- **`Section` kind switches stay closed with `never`, and this pass does not open them.** No new `Section` kind is added, only two new `FigureId` values consumed through the existing `embed` arm and one new instance of the existing `figure` arm. `src/components/sections.tsx`, `tests/unit/content.test.ts` and `tests/export/figures.test.ts` need zero edits.
- **Figure provenance is mandatory.** Every entry in `scripts/extract-figures.py` carries a `why`.
- **Alt text is copy.** It reaches screen readers and the exported HTML, walked by the same copy guard as everything else.
- **Run `npm run typecheck && npm test` before every commit.** `npm run test:export` additionally runs a build and is needed once the new sections are wired into `src/content/projects.ts`.
